# Modern Magic Storage Documentation Wiki

Welcome to the technical documentation, gameplay guides, and recipe reference catalog for **Modern Magic Storage**.

Modern Magic Storage is a multi-loader, multi-version storage network mod for Minecraft supporting **Fabric**, **Forge**, and **NeoForge** across Minecraft **1.20.1**, **1.21.1**, and **26.3**.
